# {{Title}}

A deployable Smite HTTP application generated by `smite create` from tested
snippets.

## Scripts

- `npm run dev` — `smite dev`: compile, serve, auto-reload on change.
- `npm start` — `node src/server.ts`: production server over `node:http`.
- `npm test` — Vitest against `tests/app.test.ts`.
- `npm run typecheck` — `tsc --noEmit`.
- `npm run docker:up` / `npm run docker:down` — build and run the container.

## Endpoints

- `GET /health` — `{ "ok": true }`
- `GET /items` — echoes `q` (validated query)
- `GET /items/:id` — coerced numeric `id`
- `POST /items` — creates an item from the JSON body

## Docker

```bash
npm run docker:up
curl http://127.0.0.1:8080/health
```
