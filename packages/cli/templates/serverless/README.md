# {{Title}}

A deployable Smite serverless application generated by `smite create` from
tested snippets. The app runs through an AWS API Gateway v2 Lambda adapter
(`lambdaify`) and deploys with the Serverless Framework.

## Scripts

- `npm run build` — `smite build`: bundle `src/handler.ts` to `dist/` and
  generate `serverless.yml` from your routes.
- `npm run deploy` — `smite deploy serverless`: write `serverless.yml` and run
  `serverless deploy`.
- `npm run offline` — `serverless offline start`: emulate the HTTP API locally.
- `npm test` — Vitest against `tests/app.test.ts` (runs the Lambda handler).
- `npm run typecheck` — `tsc --noEmit`.
- `npm run docker:up` / `npm run docker:down` — build and run the local
  offline container.

## Endpoints

- `GET /health` — `{ "ok": true }`
- `GET /items` — echoes `q` (validated query)
- `GET /items/:id` — coerced numeric `id`
- `POST /items` — creates an item from the JSON body
